# task_3

# Вариант 13 — Координаты температурного поля двухслойной стенки

## Описание задачи

Двуслойная теплоизоляционная стенка имеет на внутренней стороне температуру
`t1 = 650 °C`, на внешней — `t2 = 45 °C`. Заданы толщины и теплопроводности
обоих слоёв. Требуется определить координаты стенки (отсчитываемые от её
внутренней стороны, в метрах), в которых устанавливаются температуры
`t = 500, 400, 250, 150 °C`.

## Исходные данные

| Величина | Обозначение | Значение |
|---|---|---|
| Температура внутренней стороны | `t1` | 650 °C |
| Температура внешней стороны | `t2` | 45 °C |
| Толщина внутреннего слоя | `δ1` | 55 см |
| Толщина внешнего слоя | `δ2` | 15 см * |
| Теплопроводность внутреннего слоя | `λ1` | 0.8 ккал/(м·ч·град) |
| Теплопроводность внешнего слоя | `λ2` | 0.2 ккал/(м·ч·град) |

\* В части изданий условия указано `δ2 = 13 см`; контрольные ответы
(0.285 и 0.650) соответствуют именно `δ2 = 15 см`, поэтому в программе
используется 15 см.

## Расчётные формулы

Температура на стыке слоёв:

```
tc = (λ1/δ1 · t1 + λ2/δ2 · t2) / (λ1/δ1 + λ2/δ2)
```

Координата точки с температурой `t` (кусочно-линейное поле):

```
x = (t - t1) / (tc - t1) · δ1,              при t > tc
x = (t - tc) / (t2 - tc) · δ2 + δ1,         при t < tc
```

## Соответствие переменных кода и условия

| Переменная в коде | В условии | Смысл |
|---|---|---|
| `tempIn` / `tempOver` | `t1` / `t2` | температуры сторон стенки |
| `wideIn` / `wideOver` | `δ1` / `δ2` | толщины слоёв, см |
| `lambdaIn` / `lambdaOver` | `λ1` / `λ2` | теплопроводность материала |
| `thermalConductanceIn` / `thermalConductanceOver` | `λ1/δ1`, `λ2/δ2` | тепловая проводимость слоя |
| `temperatureBetween` | `tc` | температура на стыке слоёв |
| `tempCoordinates` | `t` | текущая температура из списка (целая, °C) |
| `wallCoordinates` | `x` | координата от внутренней стороны, см |
| `step` | — | шаг обхода температур в циклах |
| `finishStep` | — | порог, завершающий 1-й цикл и передающий управление 2-му |

## Описание программы

- Все исходные данные вводятся с клавиатуры; приглашения ко вводу — на
  английском языке.
- Температура на стыке `tc` вычисляется через тепловые проводимости слоёв
  `thermalConductanceIn = λ1/δ1` и `thermalConductanceOver = λ2/δ2`
  (это не то же самое, что `λ`: проводимость материала делится на толщину слоя).
- Обход заданных температур выполнен **двумя циклами**:
  - цикл с **предусловием** `while` — высокие температуры (500, 400);
    завершается, когда `tempCoordinates` опускается до порога `finishStep` (300);
  - цикл с **постусловием** `do-while` — низкие температуры (250, 150);
    гарантирует минимум одну итерацию.
- Вывод результата:
  - сначала строка `Temperature at the layer interface: …` со значением `tc`;
  - затем таблица из двух колонок (`t` и `x`) с шапкой;
  - формат фиксируется один раз для всего потока: `fixed` и `setprecision(3)`
    из библиотеки `<iomanip>`;
  - ширина колонок задаётся манипулятором `setw`: 5 символов для температуры
    и 10 — для координаты;
  - температура хранится в переменной типа `int`, поэтому выводится как целая
    без дополнительных приведений;
  - координата вычисляется в сантиметрах и переводится в метры при выводе
    (`wallCoordinates / 100`).
