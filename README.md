# task_3

# Вариант 13 — Координаты температурного поля двухслойной стенки

## Описание задачи

Двуслойная теплоизоляционная стенка имеет на внутренней стороне температуру
`t1 = 650 °C`, на внешней — `t2 = 45 °C`. Заданы толщины и теплопроводности
обоих слоёв. Требуется определить координаты стенки (отсчитываемые от её
внутренней стороны, в метрах), в которых устанавливаются температуры
`t = 500, 400, 250, 150 °C`.

## Исходные данные

| Величина | Обозначение | Значение |
|---|---|---|
| Температура внутренней стороны | `t1` | 650 °C |
| Температура внешней стороны | `t2` | 45 °C |
| Толщина внутреннего слоя | `δ1` | 55 см |
| Толщина внешнего слоя | `δ2` | 15 см |
| Теплопроводность внутреннего слоя | `λ1` | 0.8 ккал/(м·ч·град) |
| Теплопроводность внешнего слоя | `λ2` | 0.2 ккал/(м·ч·град) |

## Расчётные формулы

Температура на стыке слоёв:

```
tc = (λ1/δ1 · t1 + λ2/δ2 · t2) / (λ1/δ1 + λ2/δ2)
```

Координата точки с температурой `t` (кусочно-линейное поле):

```
x = (t - t1) / (tc - t1) · δ1,              при t > tc
x = (t - tc) / (t2 - tc) · δ2 + δ1,         при t < tc
```

## Описание программы

- Все исходные данные вводятся с клавиатуры.
- Температура на стыке `tc` вычисляется через тепловые проводимости слоёв
  `g1 = λ1/δ1` и `g2 = λ2/δ2`.
- Обход заданных температур выполнен **двумя циклами**:
  - цикл с **предусловием** `while` — высокие температуры (500, 400);
    завершается через промежуточную переменную `finishstep` (порог 300);
  - цикл с **постусловием** `do-while` — низкие температуры (250, 150);
    гарантирует минимум одну итерацию.
- Результат выводится в метрах с точностью 3 знака после запятой
  (манипуляторы `fixed` и `setprecision(3)` из библиотеки `<iomanip>`).
